# HexaCart

HexaCart is an e-commerce web application developed as part of the Phase 04 assignment.

## Project Goals

- Build a colourful and user-friendly shopping website.
- Implement customer and admin functionalities.
- Work with JavaScript, JSON and REST API concepts.
- Integrate Firebase as the backend.

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery and AJAX
- JSON
- Firebase
- Git

## Project Structure

- index.html - Main website page
- css/ - Stylesheets
- js/ - JavaScript files
- assets/ - Images and other resources
- README.md - Project documentation
