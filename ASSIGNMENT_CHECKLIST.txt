SECURITY / SCOPE NOTES
---------------------
The browser app uses Firebase REST APIs and Firebase Security Rules. It is an
assignment/demo implementation, not a production payment backend. For a real
commerce deployment, move checkout validation, credit accounting, and
collision-proof ID allocation to trusted Cloud Functions or a server using the
Firebase Admin SDK. Do not trust browser-supplied prices or totals in a
production checkout. Do not commit passwords or service-account credentials.

The PDF specifies a default credit limit of 0 and separately mentions a 1000
credit amount in the purchase description. This implementation follows the
explicit profile default of 0; an administrator assigns a limit.
